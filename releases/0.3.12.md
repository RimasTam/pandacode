# Railway deploys and Android emulators on Windows

This is a release of the RimasTam/pandacode fork, based on PandaCode 0.3.11. It updates itself from this fork's releases.

## Deploys

- **Deploy to Railway.** The header Deploy menu has a Railway entry. Connect Railway in Settings → Agents → Cloud sandboxes with an account token, or a workspace token and its workspace ID. The agent then creates the project, deploys with `railway up`, gives it a public URL and checks that it works.
- **No extra download in the installer.** PandaCode uses the Railway CLI if you have it installed. Otherwise it fetches a pinned version (about 8 MB) the first time an agent deploys.
- **Your token stays out of the agent's hands.** The CLI gets the token only in its own environment, and it is removed from the output. Railway's telemetry and self-update are turned off. Commands that would sign in, open a local shell or call the raw API are refused.

## Simulators

- **Android emulators on Windows.** The Simulators tab now appears on Windows and lists the Android emulators from your Android SDK. Agents can drive them like they do on macOS. Without an SDK, the tab points you to Android Studio.

## Updates

- **This fork has its own update key.** Updates are signed with the fork's key and served from this fork's releases. Copies installed from the upstream project, or from an earlier local build of this fork, cannot update to it automatically. Install this release once, and later fork releases arrive on their own.

## Known limitations

- Railway deploys have not been tried against a live Railway account yet.
- The installers are not code-signed, so expect the usual first-launch warnings.
